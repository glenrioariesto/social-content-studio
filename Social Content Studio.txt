Bisa. Kalau kebutuhanmu adalah dashboard lokal untuk mengelola konten dari beberapa akun sosial media, dengan HTML sebagai sumber konten dan FFmpeg sebagai engine rendering video, saya sarankan arsitekturnya dibuat seperti local content production studio, bukan CMS biasa.

Karena kamu tidak ingin database, metadata dan status konten bisa disimpan sebagai file JSON lokal, sedangkan asset seperti HTML, gambar, audio, video, dan hasil render disimpan dalam folder.

2. PRD — Social Content Studio
Product Vision

Membangun aplikasi desktop/local web dashboard untuk mengelola proses produksi konten sosial media dari tahap ide, pembuatan HTML, rendering menggunakan FFmpeg, sampai konten siap dipublikasikan ke berbagai akun dan platform.

Aplikasi berjalan 100% lokal sehingga:

tidak membutuhkan database server
tidak membutuhkan cloud storage
asset berada di komputer
rendering menggunakan resource komputer sendiri
metadata menggunakan JSON
dapat digunakan tanpa internet untuk proses produksi
hasil video dapat langsung digunakan untuk upload ke platform sosial media
